# React Fiber

React Fiber is cooperatively-scheduled rendering engine.**_Duh_**.

## What does that event mean

- effectively, we're not necessarily reducing the time takes to render the UI, we're just trying to be a bit smarter about it.

- **\_React Fiber**\_ introduces this idea of priority as opposed to simply, dealing with requests in the order that they were received.

- The key feature is that it can stop what it's doing and throw away an in-progress render whenever it feels like it.

React Fiber is basically a bunch of plain function, a linked-list tree, and a small scheduler in a trench coat.

Basically if something **_more important_** comes along, it can turn its focus and put the less important stuff on pause or toss it out for now and start over later.
