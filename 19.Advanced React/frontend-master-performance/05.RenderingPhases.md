# Rendering Phases

Inside of each render, there are two trees.

1. current tree: reference to the DOM
2. working progress tree

## The rendering Phases

One thing at a time.

- Take the next Fiber
- run `beginWork(fiber, renderLanes)`. Basically, call the component function, derive the children.
- If there are children, descend. If not, bubble up via `completeWork` to finalize the node, update the DOM, and collect any effects.
- But, along the way -- ask _should I yield?_ if yes, pause for a moment and let the browser have the wheel back for a second.
- Pick up where you left off.
