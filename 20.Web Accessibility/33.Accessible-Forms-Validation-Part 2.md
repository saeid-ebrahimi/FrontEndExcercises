As we mentioned in [the first part](https://practical-accessibility.today/chapters/form-validation/) of this chapter, client-side validation is no substitute for server-side validation.

Ideally, you want to think of client-side validation as an enhancement on top of server-side validation. If JavaScript is available, the script runs and you can validate the form and help the user correct any errors in it before any data is submitted to the server. Otherwise, the form should submit and the data validated on the server.

Server-side validation will always happen after the form is submitted.

Client-side validation can happen either on form submission, or inline.
